# 중앙대 학교 상세 페이지 설계

## 목적

`schools/sungkyunkwan.ts` 와 같은 깊이의 중앙대(`cau`) 페이지 데이터를 작성하고, `ready=true`로 전환해 학교 리스트에서 활성화한다. 컴포넌트 재사용 — 새 섹션 타입은 만들지 않는다.

## 컨텐츠 출처

강사님 제공 2027학년도 입학전형시행계획 자료 (논술 일반형 p.20, 창의형 p.21, 학생부 반영 p.42-43, 핵심 변화 요약 슬라이드).

## 페이지 내러티브

중앙대 2027의 핵심 메시지: **"두 갈래의 기회와 한 가지 함정"**

1. 다빈치 캠퍼스 수능최저 완전 폐지 — 다빈치 노리는 학생에게 새 기회
2. 논술(창의형) 신설 — 현역만, 수능최저 없음, 의학부 4명/약학부 8명
3. 영어 1·2등급 통합 → 1등급 간주 — 다른 학교엔 없는 혜택
4. 재수생 함정 — 창의형 응시 불가, 무조건 일반형으로

## 섹션 구성

기존 `SchoolData` 타입과 섹션 컴포넌트 그대로 사용:

| # | 타입 | 내용 |
|---|------|------|
| 1 | `hero` | "전형 신설 & 다빈치 수능최저 폐지" |
| 2 | `change` | 다빈치 캠퍼스: 2026 최저 있음 → 2027 최저 없음 |
| 3 | `change` | 일반형 vs 창의형 비교 (재수생 가능/현역만, 최저 적용/없음 등) |
| 4 | `minReq` | 캠퍼스·단위별 최저 (서울 인문·자연 3합6, 약학·의학 4합5, 다빈치 없음, 한국사 4) |
| 5 | `warning` | 재수생 함정 — 창의형 응시 불가, 일반형으로만 지원 가능 (수능최저 부담 발생) |
| 6 | `tamgu` | 탐구 상위 1과목 반영 (의학부만 2과목 평균), 제2외/한문 미반영 |
| 7 | `matrix` | 계열별 모집단위 × 출제유형 (언어논술 / 수리논술), 일반형 기준 |
| 8 | `caseStudy` ×2 | (1) 다빈치 노리는 학생의 새 기회, (2) 재수생 함정 — 어시스턴트 초안 후 강사님 검토 |
| 9 | `strategy` | (a) 수능최저 부담 없는 다빈치 노리기, (b) 창의형 vs 일반형 선택 기준, (c) 영어 1·2등급 통합 → 1등급 간주 룰 적극 활용 |

### 자료 부족으로 포함하지 않는 섹션

- `funnel` — 중앙대 실질 경쟁률 데이터 없음 (성균관대 분석엔 있었음)
- `tieBreak` — 동점자 처리 기준이 자료에 없음

필요해지면 추후 추가.

## 새로 발생하는 일

- `src/data/schools/cau.ts` 생성
- `src/data/schools/index.ts` 수정: `import { cauData } from './cau';`, `schoolMetas` 의 `cau` 항목 `ready: true`, `schoolDataMap` 에 등록
- 학교 리스트 페이지에서 자동으로 활성 상태 표시됨 (별도 페이지 변경 없음)

## 검토 포인트 (구현 후)

1. 케이스 스터디 2개는 자료에 명시된 룰만으로 구성된 추론. 학생 사례가 아니라 "룰이 이런 시나리오에 어떻게 작용하는가" 형태.
2. 의학·약학 모집단위는 일반형/창의형 둘 다 다뤄야 함 — `matrix`는 일반형 기준, 창의형 차이는 `change` 섹션 #3에서 다룸.
3. 케이스 스터디 검토 워크플로우: 어시스턴트가 `cau.ts`에 케이스 초안을 작성 → 배포 후 강사님이 사이트에서 확인 → 수정 사항 채팅으로 알려주시면 반영. 별도 검토 절차 두지 않음.

## 향후 학교 페이지 작업의 템플릿

중앙대 결과물을 향후 다른 학교(가천·건국·경희 등) 작업 시 그대로 복제 + 학교별 데이터로 치환할 수 있는 "second school" 기준점이 된다.
