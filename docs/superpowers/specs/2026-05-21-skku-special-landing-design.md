**Date:** 2026-05-21
**Author:** 조우제수리논술LAB
**Status:** Draft (브레인스토밍 산출물)

## 1. 개요

조우제수리논술LAB가 2026년 8월 개강하는 **성균관대학교 수리논술 대비 4회 단기 특강**을 위한 **단일 랜딩페이지**를 신설한다. 사이트 메인 네비게이션에는 노출하지 않고, 상단 EventBanner와 홈 Hero의 보조 CTA, 그리고 카톡·인스타·맘카페 등 외부 채널로 유입되는 전용 페이지 형태로 운영한다.

### 1.1 핵심 마케팅 메시지

페이지 전체가 **두 개의 무기**를 중심으로 구성된다.

1. **출제범위 박제** — 성균관대 모집요강 원문(`수학, 수학Ⅰ, 수학Ⅱ — 3문제 / 100분`)을 그대로 인용해 "확통이든 미적분이든 동일한 시험"임을 공식 근거로 박는다. 학부모의 의심을 봉쇄하는 카드.
2. **실질 경쟁률 반전** — 표면 127.95라는 압도적 숫자를 정면으로 마주한 뒤, 실제 응시율과 수능최저 통과율을 곱해 실질 경쟁률은 표면의 1/8 수준임을 보여준다. 기존 `/schools/sungkyunkwan` 페이지의 funnel 분석을 압축 재사용.

추가 감성 무기: 강사 조우제가 **성균관대 동문**이라는 점과, 성균관대 슬로건 *"예로부터 나라의 인재는 성균에 모여 왔으니, 그대 머묾이 우연이겠는가"* 인용.

### 1.2 사용자 목표

- **1차**: 카톡·인스타·카페에서 링크 받은 학부모/학생이 5분 이내에 신청 의사를 결정하도록 유도
- **2차**: 의사결정 직후 전화·카톡으로 문의를 발생시킴 (전환)
- **3차**: 공유 시 OG 미리보기로도 메시지가 전달됨

## 2. 라우팅 및 사이트 통합

### 2.1 라우트

- **URL**: `/sungkyunkwan-special`
- **App.tsx 라우팅**: 기존 `currentPath` state 기반 path routing 패턴을 그대로 따른다. `currentPath === '/sungkyunkwan-special'` 조건으로 `<SkkuSpecialPage />` 렌더.
- **메인 네비게이션**: **추가하지 않음**. 랜딩페이지 전형 패턴 유지.

### 2.2 유입 경로

| 경로 | 처리 |
|---|---|
| 상단 EventBanner | `events.ts`에 8/2 개강 이벤트를 추가하고, EventBanner 클릭 시 `/sungkyunkwan-special`로 이동 (기존 `#event` 스크롤 동작과는 별도 분기) |
| 홈 Hero | 기존 "합격 전략 보기" 버튼 옆에 보조 버튼 추가 (예: "성균관대 특강 안내") |
| 외부 공유 | OG 메타 태그로 카톡·인스타 미리보기 메시지 노출 |

### 2.3 EventBanner 분기 처리

현재 `EventBanner` 클릭은 `navigateToEventSection`을 호출해 `/about#event`로 스크롤한다. 8/2 특강 이벤트는 다른 경로(`/sungkyunkwan-special`)로 보내야 하므로:

- 이벤트 데이터에 옵셔널 `link` 필드 추가 (`Event.link?: string`)
- EventBanner의 onClick은 이벤트에 `link`가 있으면 해당 경로로 이동, 없으면 기존대로 `#event` 스크롤
- 이렇게 하면 다른 일반 설명회 이벤트와도 공존 가능

### 2.4 OG 메타 태그

- `og:title`: "성균관대 수리논술 대비특강 — 조우제수리논술LAB"
- `og:description`: "출제범위 수학·수학Ⅰ·수학Ⅱ — 확통/미적분 무관. 성균관대 동문 강사가 직접 지도하는 4회 압축 특강."
- `og:image`: 강사 프로필 또는 성균관대 슬로건 카드 형태 이미지

`index.html`의 정적 메타 태그로 처리 (사이트가 SPA지만 단일 랜딩이므로 동적 메타는 불필요).

## 3. 페이지 섹션 상세

총 10 섹션. 각 섹션은 독립된 컴포넌트로 분리하고 `src/components/skku-special/` 디렉터리에 모은다.

### 3.1 ① HERO

**컴포넌트**: `SkkuSpecialHero`

**구성**:
- 상단: 성균관대 슬로건 인용 (서브 헤더, 정자체 작은 글씨)
  > *"예로부터 나라의 인재는 성균에 모여 왔으니, 그대 머묾이 우연이겠는가"*
- 메인 카피 (h1):
  > **확통이든 미적분이든,
  > 성균관대 수리논술은 같은 시험입니다.**
- 보조 카피 (서브 텍스트):
  > 출제범위는 수학·수학Ⅰ·수학Ⅱ. 선택과목으로 갈리지 않습니다.
  > 성균관대 동문 강사가 직접 지도하는 4회 압축 특강.
- 우측 또는 하단: 강사 사진 (`/profile.png` 재사용)
- CTA 버튼: `[📅 신청·문의]` — 페이지 내 ⑤ 특강 정보 카드로 부드럽게 스크롤 (`scrollIntoView`). 페이지 내 모든 CTA는 동일한 동작 패턴을 따른다 (외부 신청 폼 없음 → 전화·카톡 문의가 최종 행동이며, ⑤ 카드에 전화 버튼이 있음).

**디자인 톤**: 기존 `AboutPage` 의 hero(`linear-gradient`, `bg-math-pattern`)와 일관성 유지하되, 성균관대 컬러(짙은 청록 + 은행나무 노랑)와 사이트 컬러(`--primary-deep-forest`, `--accent-gold`)의 조화를 모색. 본 사이트 색상을 우선.

### 3.2 ② 결정적 증거 박스 — 출제범위 박제

**컴포넌트**: `ExamScopeProofBox`

**구성**:
- 섹션 제목: "공식 모집요강 그대로"
- 카드 형태로 모집요강 원문 인용:
  ```
  ┌─────────────────────────────────────────┐
  │ 성균관대학교 2026학년도 수시모집 요강    │
  │ ─────────────────────────────────────── │
  │ 시험형식: 논술                          │
  │ 평가시간: 100분                         │
  │ 시험내용: 수학, 수학Ⅰ, 수학Ⅱ — 3문제   │
  │ 논술시험: 2025-11-16(일)                │
  └─────────────────────────────────────────┘
  ```
- 카드 아래 강조 라인:
  > ❌ 미적분 · ❌ 확률과 통계 · ❌ 기하 — **출제 범위에 없습니다.**
- 결론:
  > 선택과목과 무관하게, 모든 응시자가 같은 시험을 봅니다.
- (옵션) 모집요강 PDF 캡처 썸네일 또는 출처 표기: "출처: 성균관대학교 입학처 2026 수시모집 요강"

**데이터**: 정적. 컴포넌트 내부에 하드코딩.

### 3.3 ③ 시험·전형 핵심 일정

**컴포넌트**: `KeyDatesTimeline`

**구성**:
- 큰 카운터: 논술시험까지 **D-Day** (오늘 기준 자동 계산)
- 일정 카드 3개:
  - 논술시험: 2025-11-16(일)
  - 시험장 발표: 2025-10-28(화)
  - 시험장 발표: 성균관대 입학안내 홈페이지
- 수능 최저학력기준 요약 미니 표 (기존 `/schools/sungkyunkwan` 페이지에 이미 있는 데이터 → 압축 인용):
  - 의예과: 4개 영역 중 3합 4
  - 자유전공·반도체·약학 등: 3합 5
  - 자연과학·공학·건설환경 등: 3합 6
- 링크: "수능최저·교차지원 함정 자세히 보기 →" → `/schools/sungkyunkwan`

**D-Day 계산**: 시험일 `2025-11-16`. 단, 이 날짜는 작년 기준이라 사용자 검토 필요 — 2026 입시면 시험일이 2026-11-15 전후가 되어야 함. ⚠️ 사용자 검토 사항으로 두고 placeholder 처리.

### 3.4 ④ 작년 경쟁률 + 실질 경쟁률 인사이트

**컴포넌트**: `CompetitionInsight`

**구성**:
- 큰 숫자 3개 (`grid` 카드):
  - 모집 **204**명
  - 지원 **26,101**명
  - 표면 경쟁률 **127.95 : 1**
- 반전 인사이트 박스:
  > 표면 경쟁률 127.95는 **허수**입니다.
  > - 실제 시험장 응시율: 약 **44.7~46.5%**
  > - 그 중 수능최저 통과자: 약 **28%**
  > - → 실질 경쟁률: 약 **16 : 1**
  > 표면의 **1/8** 수준입니다.
- 학과별 경쟁률 미니 표 (collapsible — 기본 접힘):
  - 자유전공 116.47, 사회과학 134.80, 경영 124.80, 글로벌리더 80.20, ...
  - 약학 515.40, 의예 567.00 (이 둘은 별도 색상으로 경고 표기)
  - 데이터 출처: 2025학년도 입시결과 (사용자 제공 이미지)

**데이터**: `src/data/skkuSpecial.ts` 신설 — 경쟁률 데이터 배열로 관리. 이 페이지 외에서도 재활용 가능하도록 export.

### 3.6 ⑥ 강사 — 모교를 가르치는 동문

**구성**:
- 강사 사진 (`/profile.png`)

### 3.7 ⑦ 수업 방식 (왜 이 특강인가)

**컴포넌트**: `TeachingApproach`

**구성**: 3개 pillar 카드 (`AboutPage`의 logic-vs-problem-solving 패턴과 유사)
- **1:1 답안 첨삭** — 4회 모두 답안을 직접 손으로 첨삭
- **성균관대 기출 직접 풀이** — 최근 5년 기출을 회차별 분배
- **4회 압축 커리큘럼** — 단답 → 서술 → 모의시험 → 총정리

**데이터**: 컴포넌트 내부 정적.

### 3.8 ⑧ 합격 후기

**컴포넌트**: `ReviewsSection`

**구성**:
- 카드 3장 (기존 `aboutData.ts`의 `reviewData` 재활용)
- **우선 큐레이션**: 성균관대 합격생 후기가 있으면 그것을 먼저 노출. 없으면 전체 후기 중 상위 3개.
- ⚠️ placeholder: 사용자가 성균관대 합격생 후기 별도 큐레이션 의향이 있는지 미확정. 일단 `reviewData` 전체에서 첫 3개 노출하는 형태로 구현하고, 사용자가 별도 큐레이션을 원하면 후속 수정.

### 3.9 ⑨ FAQ

**컴포넌트**: `FaqSection`

**구성**: accordion 형태 4문항

| Q | A |

| 확통 선택자도 정말 동일한 시험인가요? | 네. 성균관대 모집요강의 출제범위는 "수학, 수학Ⅰ, 수학Ⅱ"로 명시되어 있으며, 선택과목(미적분·확통·기하)은 출제 범위에 포함되지 않습니다. |

| 언어형/수리형 교차 지원 가능한가요? | 가능합니다. 두 전형은 별개로 운영되며 중복 지원 가능합니다. 단, 이과생이 언어형을 지원하는 경우 수학 영역 의무 반영 함정이 있으니 주의가 필요합니다. |
| 수업 장소는 어디인가요? | 문의 시 안내드립니다. 우측 하단 전화 또는 카톡으로 연락 주세요. |

## 6. 에러·엣지 케이스

| 케이스 | 처리 |
|---|---|

| 특강 종료 후 페이지 접근 | 페이지 자체는 남겨두되, ⑤ 특강 정보 카드 상단에 "본 특강은 종료되었습니다" 노출 (사용자 결정 사항 — placeholder). 또는 종료 후 페이지 비활성 처리. |
| 카톡 채널 URL 미정 | "카톡 문의" 버튼은 URL이 설정되면 노출, 아니면 미노출 (조건부 렌더). |
| 모집요강 변경 (시험일·범위 등) | `skkuSpecial.ts` 단일 파일만 수정. 컴포넌트는 변경 없음. |

## 7. 테스트 전략

- 기존 사이트는 vitest + jsdom 도입되어 있음. 핵심 데이터 함수 단위 테스트 우선:
  - `skkuSpecial.ts` 데이터의 형식 검증 (테스트 필요성 낮음 — 정적 데이터)
  - `EventBanner` 의 `link` 분기 동작 (events.ts에 link 있을 때 vs 없을 때)
- 컴포넌트 렌더 테스트는 최소화 (기존 사이트도 컴포넌트 테스트 거의 없음 — 동등한 수준 유지)
- 수동 검증: 데스크탑/모바일 양쪽에서 시각 검증, FloatingContact 전화 링크 동작, OG 미리보기 (카톡 디버거)

## 9. 열린 질문 / 사용자 확정 필요 사항

스펙 작성 시점에 미확정인 항목들. 구현 중 또는 구현 전 사용자 확정 필요:

1. **시험일 연도**: 모집요강 이미지에는 `2025-11-16(일)` 표기. 2026 입시 일정인지 작년 일정 자료를 참고용으로 보낸 건지 확정 필요. 2026 입시면 `2026-11-15` 전후 추정.
2. **나머지 3회 회차 날짜**: 8/2 개강만 받음. 8/9, 8/16, 8/23 인지 격주인지 확정 필요. (페이지에는 일단 "총 4회, 일정 상세는 문의 시 안내"로 처리 가능)
3. **타겟 대상**: "고3 · 재수생"으로 placeholder. 학원 외부 학생 수용 여부 등.
4. **카톡 채널 URL**: 미정 → 버튼 미노출.
5. **합격 후기 큐레이션**: 성균관대 합격생 한정 노출인지, 전체 후기에서 일부 노출인지.
6. **특강 종료 후 페이지 처리**: 그대로 유지인지 비활성화인지.

이 항목들은 placeholder로 구현하고, 구현 후 사용자가 채우는 단계를 둔다.
