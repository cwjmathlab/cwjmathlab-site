# 2028 PREVIEW 카테고리 — 디자인 스펙

**작성일:** 2026-05-08
**대상 사이트:** 조우제수리논술LAB (cwjmathlab.co.kr)
**상태:** 사용자 승인 (브레인스토밍 단계)

## 배경 및 목적

기존 사이트는 `2027 DATA` 탭에 현 고3을 위한 입시 정보를 비율별/시기별/시험범위별/최저별 표로 제공한다. 2028학년도(현 고1·고2 대상) 논술전형 정보가 새로 정리되어 이를 별도 카테고리로 추가하려 한다.

원본 자료는 외부 강사가 작성한 PDF 표 기반 자료다. 따라서 단순 전재는 저작권 문제가 있고 사이트 신뢰도에도 좋지 않다. 본 페이지는 **공개적으로 검증 가능한 사실 정보(대학별 정원, 수능최저 요건, 시험 범위 발표 여부)** 만을 활용하고, **구조와 해설은 조우제 강사 본인 명의의 분석으로 완전히 재구성**한다.

## 사용자 승인 항목

- 대학 커버리지: 의대 / 약학 / 한의예 / 주요 자연계 등 계열 그룹별
- 페이지 구조: "3대 변화 키워드" 중심 (옵션 A)

## 콘텐츠 사양

### 인트로 단락 (조우제 강사 명의)
- 1~2문단, 60~120자/문단
- 톤: 분석가/멘토 (사이트 기존 카피 톤과 동일)
- 핵심 메시지: "2028은 입시 환경이 흔들리는 해. 고1·고2는 흔들림 자체를 전제로 학습 전략을 짜야 한다"

### 3대 변화 카드

각 카드는 헤드라인 큰 글씨 + 본문 텍스트 + 본문 위 또는 아래에 작은 배경색 칩으로 `stat` 표시.

| ID | 헤드라인 | 본문 메시지 | 보조 stat (칩) |
|---|---|---|---|
| `scope` | 시험 범위가 5월에도 미공개 | 대다수 대학이 출제 범위 미발표. 최상위권은 전범위, 그 외는 "공통수학 + 대수 + 미적분Ⅰ + 확률과통계" 묶음이 유력. 전범위 시나리오 대비 학습 필요. | "30개 중 25개교 미발표" |
| `minreq` | 수능최저, 다시 돌아왔다 | 연세대(자연), 인하대, 서울시립대 등에서 최저 부활. 상위권은 사실상 모두 최저 존재. 논술이 강해도 최저 미달이면 무의미. | "부활/강화 4~5개교" |
| `record` | 학생부 영향력은 약화 흐름 | 전반적으로 학생부 영향력 유지 또는 감소. 단 출결을 별도 반영하는 일부 대학(서강대·동국대·중앙대 등)은 주의. 결국 논술 + 최저 두 축이 합격을 가른다. | "출결 별도 반영 4개교" |

### 계열 그룹 블록 (5개)

각 블록은 `summary` 한 줄 + `schools` 배열로 구성. 학교 카드는 5필드: `name`, `scope`(시험 범위), `minReq`(수능최저), `quota`(정원), `note`(한 줄 코멘트).

**블록 ① 의예과**
- summary: "최저는 이미 4합 이내가 표준. 1점 차로 합격이 갈리는 그룹"
- 대상: 성균관대(의), 한양대(의), 중앙대(의), 경희대(의·치·한·약), 이화여대(의), 인하대(의), 아주대(의), 가톨릭대(의)

**블록 ② 치·한의예**
- summary: "선택지가 좁은 만큼 정원 변화에 민감하게 반응"
- 대상: 경희대(치·한), 대전대(한의예) — `NEW` 뱃지

**블록 ③ 약학**
- summary: "수능최저 4합~5합대, 시험 시간 단축 추세"
- 대상: 연세대(약), 중앙대(약), 경희대(약), 이화여대(약), 동국대(약), 숙명여대(약), 아주대(약), 가톨릭대(약), 덕성여대(약)

**블록 ④ 주요 자연계**
- summary: "정원 변화와 수능최저 부활을 동시에 살펴야 하는 그룹"
- 대상: 연세대, 고려대, 서강대, 성균관대, 한양대, 중앙대, 경희대, 서울시립대, 이화여대, 건국대, 동국대, 홍익대, 숙명여대, 숭실대, 인하대, 아주대 (총 16개)
- 정원 증감(+33, +18, +57, +47 등)과 수능최저 부활 마크는 학교 카드 우상단 칩으로 표현
- **레이아웃:** 학교 수가 많으므로 데스크탑 3열 / 태블릿 2열 / 모바일 1열 그리드

**블록 ⑤ 신설 · 부활 · 폐지**
- summary: "2028의 지형을 바꾸는 세 가지 움직임"
- 대상:
  - 대전대(한의예) — `NEW` 뱃지, "한의예에 논술 통로 신규 개설"
  - 한양대(에리카) — `REVIVED` 뱃지, "정원 +203 규모로 재가동"
  - 부산대 — `CLOSED` 뱃지, "지방 거점 한 곳이 빠지며 수도권 경쟁 심화"

### 고1·고2 행동 가이드 (체크리스트 5개)

1. 목표 대학의 최저 등급 라인을 확정하고 수능 학습량을 역산할 것
2. 출제 범위가 미발표된 대학은 전범위 + 확률과통계 포함 시나리오를 기본으로 잡을 것
3. 학생부 출결(무단결석)을 점검할 것 — 일부 대학은 별도 반영
4. 신설·부활 전형(대전대 한의예 / 한양대 에리카)은 첫 회 변동성을 감안해 안전지원 카드로만 활용
5. 2027학년도 결과(현 고3) 발표 후 5~6월에 다시 점검 — 이 시점에 시험범위 확정 발표가 나올 가능성이 높음
