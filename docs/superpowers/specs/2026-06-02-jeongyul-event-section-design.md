## 1. 배경 / 목적

## 2. 범위

- HOME(`/`) 페이지에 신규 섹션 `#jeongyul-event` 1개를 신설한다.
- `src/data/events.ts`의 기존 `2026-06-05-jeongyul` entry를 학원 문자 기준으로 교체한다.
- 상단 `EventBanner` 클릭 동선이 신규 섹션을 향하도록 한다.
- 별도 전용 페이지는 만들지 않는다. (3일짜리 단발 이벤트라 ROI 낮음)
- ABOUT 페이지 등 기타 페이지는 건드리지 않는다.
- 6/6(토) 0시부터 섹션과 배너 모두 자동으로 사라진다 (`getNextEvent` 동일 로직 재사용).

## 4. 배치 / 라우팅

### 4.1 섹션 위치

HOME 페이지(`App.tsx`)의 다음 두 영역 사이:

```
[Hero (텍스트 + 프로필 사진)]
       ↓
[★ #jeongyul-event 섹션 ★]   ← 신설
       ↓
[Stats (10년 / 1:1 / N개 / N개)]
```

이유:
- Hero에서 브랜드 첫인상을 잃지 않음
- 즉시 시급한 단발 이벤트 노출 → 행동 유도
- 그 뒤 신뢰지표(스탯)로 마무리

### 4.2 EventBanner 동선

`App.tsx`의 `navigateToEventSection` 핸들러는 이미 `link` 우선 처리 구조다.

- 기존 entry에 `link: '/#jeongyul-event'` 추가.
- 핸들러에서 `link`가 `'/#...'` 형태일 때 라우팅을 `/`로 바꾸고, 다음 tick에 `getElementById('jeongyul-event')?.scrollIntoView({ behavior: 'smooth', block: 'start' })` 호출하도록 보강.
- 기존 `/sungkyunkwan-special` 류 일반 경로 동작은 영향받지 않도록 분기.

### 4.3 자동 만료

`getNextEvent()`가 null을 반환하면(=6/6 00:00 이후):
- `EventBanner`는 이미 null 처리되어 있음.
- 신규 섹션도 같은 함수의 결과로 조건부 렌더링하여 자동 숨김.
- 별도 cron / 사람 손 작업 불필요.

### 5.1 Google Form 임베드 사양

- URL: `https://docs.google.com/forms/d/e/<formId>/viewform?embedded=true`
  - 원문 short link `https://forms.gle/6Qxde96469Ghmbpp8` 는 실제 폼의 `viewform` URL로 한 번 리졸브 후 `?embedded=true` 파라미터를 붙여서 사용한다. 이 리졸브 작업은 구현 단계 첫 스텝(브라우저에서 short link 따라가서 최종 URL 복사)으로 명시한다.
- 컨테이너 max-width: `720px` 중앙 정렬.
- iframe 속성: `width="100%"`, `height="900"` (모바일에서도 폼 전체가 보이도록 넉넉히), `frameBorder="0"`, `marginHeight={0}`, `marginWidth={0}`, `title="6/5 설명회 예약 폼"`.
- 별도 로딩 placeholder는 두지 않는다 (Google Form은 보통 1초 내 로드).
- 폼 위 1줄 안내: "아래에서 바로 예약하실 수 있습니다." (메인 CTA를 누르지 않고도 폼이 보이도록 가이드)

## 6. 시각 처리

- 섹션 배경: `var(--bg-beige)` 또는 옅은 그라데이션 카드로 Hero·Stats와 시각 분리.
- 헤드라인: `var(--primary-deep-forest)` 진녹색 + 800 굵기.
- 메인 CTA: 기존 "🆕 성균관대 특강" 버튼과 동일한 `var(--accent-gold)` 톤으로 사이트 통일감 유지.
- 분반 2-카드: 카드 배경 흰색, 좌우 border-left 색만 다르게 (개념=forest, 심화=gold) → 시각적 위계.
- 모바일(≤768px):
  - 분반 카드 세로 스택
  - CTA 3개 세로 스택 (full-width)
  - iframe 높이는 그대로 유지 (모바일에서도 폼 스크롤 자연스러움)
- iframe은 PC/모바일 모두 `max-width: 720px` 박스 안에서만 렌더링되므로 페이지 전체 폭을 차지하지 않음.
