## 처리 흐름

1. **원본 추출:** PyMuPDF로 141페이지 텍스트 → `.tmp/admissions/p001.txt ~ p141.txt`
2. **학교 페이지 매핑:** 키워드 자동 인식 → `school_ranges.txt` (32개 학교 식별)
3. **1차 facts sheet 작성:** 학교별 subagent 6개 병렬 디스패치 → md 시트 6개 산출
4. **재검토 라운드 (max effort):**
   - 5개 고위험 항목 PDF 원문 grep + 이미지 판독으로 직접 검증
   - 한양대 모집인원 표에서 **systematic column-mismatch error** 발견 → PyMuPDF `blocks` 모드로 재추출 + 합산 검증으로 수정
   - 서강대 출제범위 오해석 수정
   - 고려대 본교 시험일 잘못 기재된 부분 수정
   - 이화여대 시험일 누락을 "외부 확인 필요"로 명시화
5. **자동 검증 스크립트:** `.tmp/admissions/verify_sheets.py` 작성 → 8/8 섹션 완비 확인

## 시간/토큰 절감 기법

- **병렬 subagent 디스패치:** 6개 학교를 6개 fresh subagent에 동시 분배 → 약 2분 30초로 1차 추출 완료 (직렬 실행 대비 ~6× 빠름).
- **이미지 fallback:** PyMuPDF 텍스트가 빈 페이지(폰트 문제)를 자동 검출 → 4× PNG로 렌더링해 직접 판독.
- **`blocks` 모드 재추출:** 표가 행 단위로 깔끔히 추출 → 한양대 systematic error 5분 내 발견·수정.
- **합산 검증:** 모집인원 행의 각 전형별 인원 합 = 수시계 → 컬럼 매핑 오류를 즉시 잡아냄 ("교과+종합+논술 = 수시계" 등식이 거짓이면 매핑 오류).
