## 2. 출제 범위 (자연계)

### 자연계

- **포함 과목 (수학):** 수학, 수학Ⅰ, 수학Ⅱ, 확률과 통계, 미적분, 기하
- **제외 과목:** 과학 과목 (자연계는 수학만 출제)
- **문항 수:** 수학 6문항 내외
- **시험 시간:** 120분
- **출제 형태:** 제시문과 논제로 구성된 자료 제시형 / 문항별 지정된 답안란에 작성(노트 형식)
- **출제 특징:** 수리논술 출제 (통합형 논술 아님)
- **수준:** 고등학교 교육과정 범위와 수준 안에서 출제

### 의·약학계 (의예과, 한의예과(자연), 치의예과, 약학과)

- **포함 과목 (수학):** 수학, 수학Ⅰ, 수학Ⅱ, 확률과 통계, 미적분, 기하
- **포함 과목 (과학):** 물리학Ⅰ·Ⅱ, 화학Ⅰ·Ⅱ, 생명과학Ⅰ·Ⅱ (물리학·화학·생명과학 중 1과목 선택)
- **문항 수:** 수학 4문항 내외, 과학 4문항 내외
- **시험 시간:** 120분
- **출제 형태:** 제시문과 논제로 구성된 자료 제시형 / 문항별 지정된 답안란에 작성(노트 형식)
- **출제 특징:** 수리논술(60%) + 과학논술(40%)

## 4. 수능 최저학력기준

### 자연계 일반 (의예과, 한의예과 인문·자연, 치의예과, 약학과 제외)

- 국어, 수학, 영어, 사회/과학탐구(2과목) 중 **2개 영역 등급의 합이 5 이내**, 한국사 5등급 이내

### 의예과, 한의예과(인문·자연), 치의예과, 약학과

- 국어, 수학, 영어, 사회/과학탐구(2과목) 중 **3개 영역 등급의 합이 4 이내**, 한국사 5등급 이내

### 공통 유의사항

- 반영 영역별 필수 응시과목(지정과목) 없음 (단, 한국사 필수 응시)
- 탐구영역은 2과목 평균등급 반영 (소수점 버림 없이 그대로 반영)
- 수능 최저학력기준 미충족자는 입학전형 대상에서 제외

## 7. 기타 특이사항

- 전형 방법: 논술고사 성적 100% (수능 최저 충족자 중 선발)
- 배점: 1,000점 만점
- 동점자 처리: ① 논술고사 고배점 과목/논제/문항 성적 우위자 → ② 학생부 공통·일반선택 반영 교과 성적 → ③ 이수단위 수
- 학교폭력사실이 학생부에 기재된 경우 감점(결격) 처리
- 출제 유형: 제시문과 논제로 구성된 자료 제시형
- 자연계 논술은 수학 교과(수학, 수학Ⅰ, 수학Ⅱ, 확률과 통계, 미적분, 기하) 범위만 출제 (과학 제외)
- 의·약학계는 수학+과학 혼합 출제 (수학 필수, 과학 1과목 선택)
- 기출 논술문제·예시답안·출제개요·모의논술 특강 동영상 입학처 홈페이지(iphak.khu.ac.kr) 공개
- 합계 모집인원 471명 (전 계열 포함, 자연계+의약학계만 합산 시 PDF에 별도 수록 없음)
