## Critical Risk (시급 처리 필요)

### R1. 이화여대 시험 일정 일체 누락

- **현황:** pp.104-105 범위에 시험일·시험시간·고사장·합격자 발표일 정보 없음. 본 PDF 묶음 자체가 일정 정보를 다른 페이지에 두고 있음.
- **영향:** 학생/학부모가 가장 먼저 확인하는 정보가 비어 있음. 다음 학교 페이지 만들 때 일정 정보를 끼울 데가 없음.
- **권장 조치:** 이화여대 입학처 (admission.ewha.ac.kr) → 2027학년도 수시모집요강 또는 7월 공지 「2027학년도 논술고사 안내」 직접 다운로드해서 확정 일정을 본 시트의 §1에 채워 넣어야 함.
- **소요 시간:** ~10분.

### R2. 고려대 본교 시험일 불명

- **현황:** PDF p020-p024 범위에 본교 자연계 논술 시험일 명시 없음. 이전 추출 에이전트가 "2025년 11월 21일"이라고 적었으나 PDF 원문에서 해당 문자열을 grep으로 찾을 수 없음 — 오인 기재로 판단.
- **영향:** §1 시험일 항목이 비어 있음.
- **권장 조치:** 고려대 입학처 홈페이지 「2027학년도 수시모집요강」 본문에서 직접 확인. 또는 PDF의 다른 페이지(고려대 별도 일정표가 있을 수 있음) 추가 검색.
- **소요 시간:** ~10분.

### R6. 인하대 시험일·고사장 미수록

- **현황:** PDF 인하대 묶음(pp.106-112)에 시험일·시험시간·고사장 발표일·합격자 발표일 정보 없음. 인하대 요강 p.1-5(시험 일정)가 PDF에 미포함된 것으로 보임.
- **영향:** §1 시험 일정이 비어 있음. **단 2027 주요 변경(논술 비중 80% 상향)은 확인됨**.
- **권장 조치:** 인하대 입학처(admission.inha.ac.kr) 「2027학년도 수시모집요강」 본문에서 직접 확인.
- **소요 시간:** ~10분.

### R7. 성균관대 PDF 결과 페이지(pp.73-74) 이미지 전용

- **현황:** PDF pp.73-74가 이미지 전용 페이지로 텍스트 추출이 안 됨. 결과 발표일·전년 경쟁률·변경사항이 해당 페이지에 있었을 가능성.
- **영향:** §5·§6 일부 비어 있음. 단 §1-§3(시험·출제·모집)은 완비.
- **권장 조치:** 필요 시 해당 페이지 이미지(`.tmp/admissions/img/p073_3x.png` 등)를 추가 렌더링해 판독. 또는 입학처 홈페이지 참고.

## Important Risk (검증 권장)

### R3. 한양인터칼리지(자연) 모집인원·논술 인원 미확정

- **현황:** PDF p134 하단의 한양인터칼리지(자연) 행이 텍스트 블록 분절로 인해 깔끔히 추출되지 않음. 시트에 "30(추정) / 5(추정)"로 표기됨.
- **검증된 부분:** 한양대 자연계 논술 총합(정원 내) 약 114명 + 정원 외 4명 ≈ 118명 — 인터칼리지(자연) 5명 가정 시.
- **영향:** 자연계 총 모집인원 합산 ±5 변동. 개별 모집단위 단위 데이터 신뢰도 영향.
- **권장 조치:** 한양대 입학처 「2027학년도 수시 모집요강 본문」 또는 p134 원본 PDF 직접 확인. 5x 렌더링 이미지(`.tmp/admissions/img/p134_table_5x.png`)도 활용 가능.

### R4. 연세대 본교 자연계 모집인원 합계 불일치 (188 vs 288)

- **현황:** 이미지 4× 판독으로 자연계 28개 모집단위 정리. 자체 합산 184명 + 응용통계(통합) 4명 = 188명. 인문계 87명 더해도 275명. PDF의 합계표 표기 288명과 13명 차이.
- **검증된 부분:** 시험일(10/10 토)·출제범위(미적분·기하 포함, 확률과통계 제외)·수능최저 미적용·전형방법 일괄합산 100% 등 모든 핵심 정보 확인됨.
- **영향:** 자연계 합계가 정확히 무엇인지 단정 어려움. 개별 모집단위 단위 수치는 합산 검증 안 됨.
- **권장 조치:** 연세대 본교 모집요강 본문(또는 PDF 원본 p098 표) 재확인하여 누락된 모집단위 13명분을 식별. 의·치 논술 폐지 명시는 사실 확인됨.

### R5. 한양인터칼리지 외 systematic error 가능성 잔존 검증

- **현황:** 한양대에서 systematic error를 1차 수정. 같은 PyMuPDF `blocks` 모드로 고려대/경희대/이화여대 모집인원 표 sample 검증 → **이상 없음 확인**.
- **추가로 검증 필요:** 한양대 §5 전년 경쟁률 표 (p138). 단순 추출이라 행 매핑 검증 안 됨. 의예과 287.3 같은 이상치는 의예과 특성상 그럴듯하나 다른 값들의 정확성은 미보장.

## Minor Risk (메모 권장, 시급성 낮음)

### M1. 고려대 약학과 2026 경쟁률 165.17 — 검증 완료 (정상)

- p030 line 277에 그대로 기재. 약학과 정원 6명 ⇒ 지원 991명 → 합리적 수치. 이상치 아님.

### M2. 학교폭력 감점표 부분 누락 (연세대 미래캠, 고려대 본교)

- 1호~9호 감점 수치 중 5~9호가 추출 누락 또는 일부 값만 확인됨. 학생부에 학교폭력 조치사항이 없는 일반 학생에게는 영향 없음. 해당 학생만 별도 원본 확인 필요.

### M3. 서강대 출제범위 — 1차 수정 완료

- 원래 시트는 PDF의 "적용 교육과정 범위" 표를 "포함 출제 과목"으로 옮겨 국어·사회 과목까지 자연계 출제 대상인 것처럼 기재되어 있었음. 자연계 [수리형]은 수학 영역만 실제 출제됨을 명확히 표기로 수정 완료.

### M4. 학교별 캠퍼스 분리 처리 일관성

- 경희대: 서울캠/국제캠 분리 ✓
- 고려대: 본교/세종캠 분리 ✓
- 연세대: 본교(신촌)/미래캠(원주) 분리 ✓
- 한양대: ERICA 페이지 없음 (PDF에 ERICA 별도 정보 미수록) — ERICA는 자연계 수리논술 페이지 별도 작성 필요 시 PDF 외부 자료 참조
- 이화여대: 단일캠 ✓
